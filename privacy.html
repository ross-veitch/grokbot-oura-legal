Privacy Policy

GrokBot Oura connector — personal use by Ross Veitch.

Last updated: 21 September 2026.

What this is

A personal OAuth application so an AI assistant (Grok Bot) can read the owner’s own Oura Ring data via the Oura Cloud API.

Data we access

Only Oura data the owner authorizes (for example readiness, sleep, activity, heart rate, workouts, SpO2, and personal profile fields). No other users’ data.

How data is used

Data is fetched to answer the owner’s questions and support personal workflows. It is not sold, advertised against, or shared with third parties for their marketing.

Storage

OAuth tokens and any cached responses are stored on the owner’s assistant infrastructure under their control. Tokens are not published in chat or public pages.

Sharing

There is no multi-tenant product surface. Access is limited to the owner and systems they operate.

Retention & deletion

The owner can revoke the Oura application at any time in the Oura developer / account settings. Revoking stops further API access; local tokens can be deleted from the assistant environment.
